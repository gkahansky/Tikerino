\# Tikerino Design Spec \- Tokens v2, Motion, and Chart Annotation Language (DRAFT v0.1) \*\*Status:\*\* Draft for Guy review, 19 Sep 2026\. Not yet handed to Engineering. \*\*Builds on:\*\* \`specs/tikerino-design-tokens-v1.css\` (frozen data colours, WCAG pairings, type scale). Nothing in v1 changes; v2 only extends. \#\# Part 1 \- Design tokens v2 (extensions) \#\#\# State colours (module map, lesson states, exercise states) All pairings verified against the v1 contrast table. New tokens: \- \`--state-locked: \#9AA7B0\` \- icon/text for locked items, decorative only; lock labels always carry real text ("Finish the lesson before this one to unlock"), never colour alone. \- \`--state-current: var(--brand)\` \- the next available lesson/node. \- \`--state-done: var(--brand-ink)\` \- completed; always paired with a check icon, never colour alone. \- \`--state-error-soft: \#FDECEC\` \- error surfaces/backgrounds; error text uses \`--data-down\` (AA on paper per v1). \- \`--state-success-soft: var(--brand-soft)\` \- success surfaces, reuse of v1 mint. Rule carried forward: data colours stay inside the chart canvas and keep their frozen meaning; state colours never appear inside the canvas. \#\#\# Caption band and video frame (locks Guy's 13/9 framing rules as tokens) \- \`--caption-band-bg: \#0F2B46\` (ink) at 92% opacity, or \`\#FFFFFF\` surface with \`--line\` top border in-app. Captions use 16-18px \`--font-body\`, \`--paper\` on ink, ink on surface. Both pairings pass AA. \- \`--caption-band-height: 64px\` fixed; two lines max at 16px. The band is a separate region below the chart canvas and can never overlap it. \- \`--title-strip-height: 56px\` \- the lesson title always gets its own fully visible line above the chart, never truncated, never scrolling away. \- \`--chart-safe-inset: 12px\` \- no annotation label, caption, or control may enter this inset from any canvas edge. \- Z-order, fixed: chart canvas (0) \< annotation layer (1) \< caption band (2) \< title strip (2) \< controls (3). \#\#\# Iconography tokens \- Icon grid 24px, stroke 2px, rounded caps; sizes 20/24/32. Icons replace all emoji in app chrome (lock, play, check, streak flame, crown, XP diamond). Emoji may remain only where a platform renders them as text, never as a visual crutch in designed surfaces. \#\# Part 2 \- Motion spec Principles (from the v0.3 design page, still valid): celebrate progress; spring reveals; a haptic tick on correct; confetti reserved for exam passes. Motion teaches \- the chart draws so the eye follows time; it never decorates for its own sake. \#\#\# Durations and easings \- \`--dur-instant: 0ms\` (reduced-motion target) \- \`--dur-fast: 120ms\` \- control feedback, toggles \- \`--dur-base: 200ms\` \- reveals, state changes (matches v1 \`--motion-reveal\`) \- \`--dur-slow: 350ms\` \- screen transitions, path progression \- \`--ease-standard: cubic-bezier(0.2, 0, 0, 1)\` \- entrances and moves \- \`--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)\` \- success reveals and XP counts, subtle overshoot only \#\#\# Choreography (each with its reduced-motion mapping) 1\. \*\*Chart draw-on (narrated walkthrough).\*\* Candles appear left to right in reading order, one per narration beat, 250-400ms per candle, synced to the segment that names them. Reduced motion: chart appears complete; the current candle is indicated by the static spotlight with no transition. 2\. \*\*Spotlight.\*\* Annotation fades in 150ms after its candle finishes drawing; gentle 2px scale pulse once (not looping). Reduced motion: appear without pulse. 3\. \*\*Reveal (post-cut).\*\* The cut line holds 400ms, then post-cut candles draw on at \`--dur-base\`, then feedback card slides up \`--dur-base\`. Reduced motion: full chart shown at once, feedback card appears without slide. 4\. \*\*XP count-up.\*\* Numbers count over 600ms max, ease-out; "+12 XP" chip uses \`--ease-spring\`. Reduced motion: final values shown immediately. 5\. \*\*Correct-answer tick.\*\* Haptic tick (where supported) \+ check icon draw 200ms. Reduced motion: icon appears statically; no haptic. 6\. \*\*Streak/celebration.\*\* Small moments (lesson complete): single confetti burst, max 1200ms, under 20 particles, respects the canvas rule (never inside the chart). Exam pass is the only full-screen celebration. Reduced motion: static "Lesson complete" state, no particles. 7\. \*\*Screen transitions.\*\* Forward: new screen slides up 8px \+ fades, \`--dur-slow\`. Back: reverse. Reduced motion: crossfade only. Global: any animation longer than 400ms is interruptible (tap skips to end state). Nothing auto-plays on the path or progress screens. \#\# Part 3 \- Chart annotation language One focused annotation per teaching beat (Content contract). Annotations draw from ink/brand only, so data colours keep their frozen meaning. Every annotation ships with: shape rule, non-colour cue, label placement, and a screen-reader sentence pattern ("Candles 4 through 7 are highlighted: this range is the bounce zone."). | Annotation | Shape | Colour | Non-colour cue | Label | |---|---|---|---|---| | Candle spotlight | Dashed rounded rect around candle \+ its volume bar | \`--ink\` 70% | dashed outline | Below band, names the candle index | | Candle range | Dashed rect spanning first-last candle | \`--ink\` 70% | dashed \+ end ticks | Above range, left-aligned | | Price zone | Horizontal band across full width | \`--brand\` 12% fill, \`--brand-ink\` 1px edges | horizontal hatching | Right edge, outside plot area | | Trendline | 2px diagonal through anchor points | \`--brand-ink\` | long-dash pattern \+ arrowhead at end | At line end | | Volume highlight | Volume bars darken to \`--ink\` 45% | neutral | bar pattern change | "Volume" tag left of panel | | Moving average | 2.5px smooth line | \`--ink\` 80% | dotted pattern distinct from candles | Legend chip top-left | | Indicator panel | Separate fixed-height strip below volume | \`--surface\` bg, \`--line\` border | panel separator \+ label | Panel title in strip header | Rules: maximum one annotation family per beat; two families only when one is the persistent cut line. Annotation labels sit outside the plot area or in the caption band, never floating over candles. The cut line is the only persistent annotation and is always dashed vertical \`--ink\` 60% with the "cut" tag. Storyboard-safe region: annotations must survive a 390px-wide render with the safe inset intact; anything denser gets split into two beats. \#\# Open questions folded into stage review \- Confirm caption-band dark-ink default vs surface variant for in-app narration (video uses the surface variant already). \- Icon set production route: drawn set vs an OFL set (Phosphor/Iconoir) adapted to brand; decide before D5. \- Whether the moving-average legend chip counts as chrome (allowed) or chart data (frozen-rule risk) \- current call: chrome, lives outside the plot area.
