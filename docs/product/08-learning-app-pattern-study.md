# Learning-App Pattern Study (19 Sep 2026)
Apps inspected: Duolingo, Brilliant, Zogo (financial literacy), Elevate, Khan Academy, SoloLearn, Mimo.

## Per-app notes (condensed)
- Duolingo: one guided path, not a tree (2022 redesign); mascot at celebrations/streak reminders/empty states, never inside exercises; 2-4 minute lessons, one skill each; layered motivation (XP, streaks, leagues, gems, hearts). Accessibility weak (~55/100 web scan).
- Brilliant: interactive-first learn-by-doing; competency-based onboarding; themed loading animations; wrong answers get interactive explanations. Avoid its long sign-up + paywall before any lesson.
- Zogo: bite-sized lessons; lesson one before any form; purposeful gamification drove +50% retention YoY.
- Elevate: a named daily session ("today's training") frames return visits.
- Khan Academy: mastery grid per unit (not started / attempted / familiar / proficient / mastered). Avoid weak guidance in a huge library.
- SoloLearn / Mimo: learn one small thing, use it immediately, instant feedback; named paths with a destination.

## Recurring patterns
Design: 1) one idea per screen, 2-4 minute lessons; 2) rounded illustration-led language, but professional apps keep illustration out of the work area; 3) mascots at emotional moments only; 4) high-legibility type in the learning area, colour budget on rewards and wayfinding.
Journey: 5) single guided path beats a tree; 6) named journeys with a destination; 7) first lesson before any form or paywall.
Interaction: 8) learn by doing; 9) instant feedback, explorable explanations for wrong answers; 10) themed micro-animations at waits/transitions.
Motivation: 11) multiple parallel motivation systems; 12) streaks are the strongest daily hook (Tikerino deliberately avoids loss framing); 13) earned, specific celebrations, sized to the win; 14) real-world stakes outperform points where allowed (not allowed for Tikerino MVP).
Accessibility: 15) the category leader is beatable on contrast and alt text; Tikerino's WCAG 2.1 AA lock is a differentiator.

## Implications for Tikerino
- Journey path is the highest-value design surface: single guided path, visible destination per module, the bull as companion at milestones.
- Mastery grid alongside XP/streak/crowns.
- Feedback template must include an interactive-explorable explanation state.
- Onboarding stays short; lesson one before any account wall.
- Daily-session framing as streak support, pending product approval.
- Accessibility locks are a competitive advantage; the visual QA checklist tests contrast and alt text on every template.
