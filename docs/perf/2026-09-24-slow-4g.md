## What changed

1. Fonts self-hosted: the same Latin woff2 files Google serves (Baloo 2 v23, Nunito v32, OFL), same weights and unicode-range, declared inline in index.html. Removes a render-blocking third-party stylesheet and two origins. Tried `rel=preload` on them: CLS went to 0 but LCP got worse (1,252 ms), so no preload.
2. Cache headers: `/assets/*` and `/fonts/*` get `public, max-age=31536000, immutable`; index.html, sw.js, registerSW.js and the manifest get `no-cache` so deploys still land.
3. Startup chunks (App, app-state) are `modulepreload`ed from index.html instead of waiting for the entry script to run.
4. Service worker registration script is deferred.

Compression: Railway's edge already gzips (checked on production). Brotli was not added.

## Not fixed (needs a visible or code change - for a later card)

- INP: the slowest interaction is a screen change (about 150 ms of processing at 4x CPU). The 200 ms production reading sits on the "good" line. Improving it means changing how screens render, which is out of scope here.
- Latin-only fonts: any character outside Google's Latin range (for example the shekel sign) would fall back to a system font. None is in the app today.
