## Concepts (`concepts/`)
Concept sketches that explain the structure. They are **not production art**.
- `hall-2-numeracy.jpg`: "one hall per module". The floor plan, path and gates match hall 1, the installations change per module, and the hall ends in an exam exit door instead of the bell.
- `course-overview.jpg`: the course as a tower of halls. The path climbs floor to floor, a marker shows the current hall, and the bell sits on the roof as the single final destination (P16 capstone).

Known issue: `hall-2-numeracy.jpg` has a "%" mark on the pie dial. Production art must have no baked-in text or symbols.
